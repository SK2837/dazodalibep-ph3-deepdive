**Correction note (re-verified directly against the PDF):** the Schirmer's test row
below was originally transcribed with the wrong direction (≥5mm) — the actual criterion
is **≤5mm/5min in at least one eye** (low tear production, the clinically correct
direction for a Sjögren's diagnostic criterion), now fixed below. Four other specific
numeric corrections were suggested by an external review of this project (Population 2
ESSPRI-total/Dryness values, Population 1 placebo OSDI, Population 2 placebo salivary
flow) — on re-checking the PDF directly, all four values already in this table matched
the source, and the review's proposed changes did not (they appear to reflect the
ESSPRI-total and Dryness rows being swapped for Population 2). Those four values are
therefore left unchanged from the original transcription. This is flagged explicitly
so the discrepancy isn't silently resolved either way.

## Read-across to the Phase 3 populations (corrected)

**Correction: the argument below about "Phase 3 has a looser entry bar than Phase 2"
has been removed.** Population 1's actual Phase 2 eligibility criterion was already
ESSDAI≥5 — the same floor as NCT06104124 — per the paper's methods section
("Population 1 included participants with moderate-to-severe systemic disease
activity, ESSDAI total score ≥5"). Population 2's Phase 2 eligibility was ESSPRI≥5,
ESSDAI<5, and residual stimulated salivary flow ≥0.1 mL/min — matching NCT06245408's
criteria closely, not more loosely. Phase 2's *observed* mean baseline (10.1–11.4 for
Population 1) being higher than the eligibility *minimum* (5) does not establish that
Phase 3 will enroll a different average severity — that would require actual
information about who Phase 3 enrolled, which is not yet public. This was an
unsupported inference from observed mean to eligibility floor and should not be used
in any modeling that follows.

**A more concrete, source-backed transportability question** (from Extended Data
Table 1 of the Phase 2 paper): systemic patients (Population 1) without concomitant
RA/SLE had a placebo-adjusted ESSDAI change of approximately −1.6, versus
approximately −3.3 among those with concomitant RA/SLE. Subgroup sizes are small
(RA/SLE overlap was 19.4–23.7% of Population 1), so this shouldn't be treated as a
strong interaction effect — but if NCT06104124's enrolled population has a different
RA/SLE-overlap proportion than Phase 2, that's a real, evidenced reason effect size
could differ, unlike the removed enrollment-bar argument above.

- **Demographic makeup** (>90% female, mostly SS-A antibody positive) is consistent
  with the general Sjögren's patient population and both Phase 3 trials' eligibility
  criteria — no material red flags on generalizability from these baseline tables.
